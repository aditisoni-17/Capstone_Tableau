# Data Dictionary

## Online Retail Dataset — Column Definitions

This document describes each column in the raw and processed datasets used in this project.

---

## Raw Dataset (`data/raw/data.csv`)

| Column | Data Type | Description |
|--------|-----------|-------------|
| **InvoiceNo** | String | Unique 6-digit invoice number. Invoices prefixed with **'C'** indicate **cancellations/returns**. |
| **StockCode** | String | Unique 5-digit product (item) code assigned to each distinct product. |
| **Description** | String | Product name/description. May contain missing values for some transactions. |
| **Quantity** | Integer | Number of units purchased per transaction line. **Negative values** indicate returned items. |
| **InvoiceDate** | String | Date and time of the invoice in `MM/DD/YYYY HH:MM` format. |
| **UnitPrice** | Float | Price per unit in **British Pounds Sterling (£)**. |
| **CustomerID** | Float | Unique 5-digit customer identifier. **Missing** for ~25% of transactions (anonymous purchases). |
| **Country** | String | Country of residence of the customer. |

---

## Cleaned Dataset (`data/processed/cleaned_data.csv`)

All columns from the raw dataset (with transformations applied), plus the following derived columns:

| Column | Data Type | Description |
|--------|-----------|-------------|
| **InvoiceNo** | String | Same as raw — cancellation rows removed. |
| **StockCode** | String | Same as raw. |
| **Description** | String | Same as raw. |
| **Quantity** | Integer | Same as raw — only positive values retained. |
| **InvoiceDate** | Datetime | Converted from string to `datetime64` format. |
| **UnitPrice** | Float | Same as raw. |
| **CustomerID** | Integer | Converted from float to integer — rows with missing values removed. |
| **Country** | String | Same as raw. |
| **Revenue** | Float | **Derived column:** `Quantity × UnitPrice`. Represents line-item revenue in £. |
| **Year** | Integer | **Derived:** Year extracted from InvoiceDate (2010 or 2011). |
| **Month** | Integer | **Derived:** Month extracted from InvoiceDate (1–12). |
| **DayOfWeek** | String | **Derived:** Day name extracted from InvoiceDate (e.g., Monday, Tuesday). |
| **Hour** | Integer | **Derived:** Hour extracted from InvoiceDate (0–23). |

## Summary Tables (`data/processed/`)

### `kpi_summary.csv`
| Column | Description |
|--------|-------------|
| KPI | Name of the key performance indicator |
| Value | Computed value of the KPI |

### `monthly_revenue_summary.csv`
| Column | Description |
|--------|-------------|
| YearMonth | Year-month period (e.g., 2011-01) |
| TotalRevenue | Sum of revenue for the month |
| TotalOrders | Count of unique invoices |
| TotalCustomers | Count of unique customers |
| TotalQuantity | Sum of quantities sold |
| AvgOrderValue | Average order value for the month |

### `product_summary.csv`
| Column | Description |
|--------|-------------|
| StockCode | Product code |
| Description | Product name |
| TotalRevenue | Total revenue generated by product |
| TotalQuantity | Total units sold |
| OrderCount | Number of orders containing this product |
| CustomerCount | Number of unique customers who bought it |

### `country_summary.csv`
| Column | Description |
|--------|-------------|
| Country | Customer's country |
| TotalRevenue | Total revenue from that country |
| TotalCustomers | Number of unique customers |
| TotalOrders | Number of unique orders |
| TotalQuantity | Total units sold |

### `customer_summary.csv`
| Column | Description |
|--------|-------------|
| CustomerID | Unique customer identifier |
| TotalRevenue | Lifetime revenue from this customer |
| OrderCount | Number of orders placed |
| TotalQuantity | Total items purchased |
| AvgOrderValue | Average revenue per transaction |
| FirstPurchase | Date of first purchase |
| LastPurchase | Date of last purchase |
| Country | Customer's country |
| UniqueProducts | Number of distinct products purchased |
| IsRepeat | 1 = repeat customer, 0 = one-time buyer |
| Segment | "High Value" or "Low Value" based on median revenue |

## Data Quality Notes

- **Missing CustomerID:** 135,080 rows (24.9%) removed during cleaning — these represent anonymous/guest transactions.
- **Negative Quantities:** 8,905 rows removed — these represent cancellations and returns.
- **Duplicates:** 5,192 exact duplicate rows removed.
- **Date Range:** December 1, 2010 — December 9, 2011 (~12 months of transactional data).
- **Geography:** 38 countries represented; United Kingdom accounts for ~82% of revenue.
